# Privacy

YTM Linux Desktop does not implement custom analytics, tracking or telemetry.

## Google account authentication

Google account authentication is performed by Google's own web interface.

The application does not request, receive or store your Google password in application code.

## Local session data

Electron/Chromium stores browser session data locally in the user's application profile so authentication can persist between launches.

This data is not stored inside the Git repository.

## Third-party services

The application loads YouTube Music and related Google services.

Those services may collect information according to their own terms, privacy policies and implementation.

YTM Linux Desktop does not control those services.
